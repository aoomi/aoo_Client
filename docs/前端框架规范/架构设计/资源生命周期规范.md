# 资源生命周期规范

- 场景、弹窗和动态玩法入口分别拥有自己的资源作用域。
- 动态加载的资源、运行时创建的贴图、实例节点、音频和 Bundle 都必须登记所有者。
- `Modules/<模块>/Atlas` 只保存该模块专用图片与图集；跨模块共享视觉只保留在 `Common/Atlas` 单份并由模块引用。禁止以模块自包含为由复制共享资源，发现 Common 原件与模块副本并存时必须保留权威单份并修正引用。
- `Client/assets/Games/Common` 是公共牌局场景、Prefab 与代码的统一资源作用域，唯一父级 Bundle 为 `games-common`；`GameRoom2D`、ChatPanel、语音和解散等资源从该 Bundle 加载，子目录不得再声明嵌套 Bundle 或建立同资源平行发布路径。
- `Client/assets/Games/Poker/Common` 是扑克公共资源作用域，唯一父级 Bundle 为 `poker-common`；`Prefab/SmallSettle`与`Prefab/BigSettle`必须继承父 Bundle，不得继续声明 `poker-small-settle`、`poker-big-settle` 子 Bundle 或恢复其平行加载路径。目录 `.meta` 变更必须在 Creator 3.8.8 无未保存结算编辑现场时串行执行，并完成正常重导入、Preview 与真实 E2E。
- `Client/assets/Club/Prefab` 由目录 `.meta` 独立声明为 `club-prefab` Bundle；`ClubDesk` 的权威加载地址为 `club-prefab/ClubDesk`，不得继续把父 Bundle `club` 下的 `Prefab/ClubDesk` 当作正式地址。旧父 Bundle 路径仅可作为迁移期集中兼容回退，不构成第二资源归属，确认无旧发布消费者后应移除。
- Bundle 归属以资源目录 `.meta` 与实际加载器为准；场景属于独立 Bundle 时不得要求同时出现在 main Bundle，也不得因 `assets/main/config.json` 未列出而复制或恢复旧资源。
- 页面关闭或节点销毁时统一释放监听器、定时器、请求回调、节点和资源引用。
- 共享资源只归应用级作用域，禁止同时归属页面作用域。
- 同一资源重复归属、释放后继续使用或页面退出仍持有资源，均视为错误。
