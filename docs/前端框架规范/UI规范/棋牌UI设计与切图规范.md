# 棋牌 UI 设计与切图规范

本文只规定视觉设计与图片交付，不规定代码、场景跳转或业务流程。

## 设计尺寸

- 整屏背景固定为 `1600×720`。
- 其他 UI 统一使用 `1280×720` 坐标系；背景左右各有 `160px` 延展区。
- 关键文字和交互控件必须位于中间安全区。
- 背景等比覆盖或自然延展，禁止横向拉伸人物、文字和装饰。

## 任务类型

开始前必须明确是重新设计、原图提取、原图修复、透明抠图、尺寸调整、九宫格还是状态图。

- 原图提取不得重绘或调色。
- 原图修复只能补指定遮挡区。
- 没有源像素时只能标注为推断修复，不能声称是原版。

## 图片与透明

- 透明资源使用真实 Alpha PNG；禁止白底、灰底或棋盘格冒充透明。
- 按有效像素紧边裁切，完整保留阴影、外发光和抗锯齿边缘。
- 透明像素的 RGB 清零，边缘不得有白边、黑边、色边或锯齿。
- 半透明纹理保留连续 Alpha 层次，不做硬阈值抠图。
- 动态文字默认由 Cocos Label 渲染，不烘焙进底板。

## 九宫格

- 仅对中心可安全拉伸、四角和边框不可变形的底板使用。
- 必须记录 `left/right/top/bottom` inset。
- 纯色拉伸区只保留 `50px`；装饰、描边、斜边和渐隐留在不可拉伸区。
- 至少验证原始、最小、常用和最大尺寸，无接缝、色差或变形。

## 控件状态

- 按需提供普通、按下、选中、禁用状态。
- 同组状态的画布、锚点、有效边界和九宫格参数必须一致。
- 状态变化不得改变点击区域或导致控件跳动。

## 命名引用

所有 UI 图片、Scene、Prefab、节点和业务目录命名统一遵循 [命名规范](../命名规范.md)，本文不再维护命名规则正文。

## 交付

- 默认使用 sRGB PNG；照片型背景经确认后可使用高质量 JPG/WebP。
- 交付清单包含像素尺寸、Alpha、九宫格 inset、锚点、用途和处理类型。
- 接入项目时还必须遵循场景规范并完成 Creator 同步；只交图片时不得顺带修改场景或代码。
