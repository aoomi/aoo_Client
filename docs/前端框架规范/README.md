# Aoo 前端文档入口

第一次接触项目，先读 [Aoo 项目框架大白话总览](../../../Server/docs/Aoo项目框架大白话总览.md)。它用普通语言说明客户端、服务端、管理后台、数据库、开房规则和完整游戏流程。

需要实际修改某个前端功能时，再按下面的分类查看详细规范，不需要从头读完所有文档。

| 你要处理什么 | 应该看哪里 |
|---|---|
| 给 Scene、Prefab、节点或图片起名 | [命名规范](./命名规范.md) |
| 设计界面、切图、透明图或九宫格 | [棋牌 UI 设计与切图规范](./UI规范/棋牌UI设计与切图规范.md) |
| 判断文件应该放哪里、谁可以引用谁 | [前端架构规范](./架构设计/前端架构规范.md) |
| 判断功能是否应该做成公共组件 | [公共组件规范](./公共组件规范/公共组件规范.md) |
| 修改页面、弹窗、场景跳转或进出房间 | [场景与弹窗规范](./场景规范/场景与弹窗规范.md) |
| 查具体玩法或产品流程 | [玩法与产品](./玩法与产品/) |
| 查某次迁移、修复和验收证据 | [历史记录与证据](./历史记录与证据/) |

简单原则：先按当前任务读取一份对应规范；只有出现跨模块问题时，再继续查其他规范。历史材料只用于追溯，不能覆盖现行规则。

`开房规则表` 由用户维护且保持原目录，只读，不属于前端框架文档。
