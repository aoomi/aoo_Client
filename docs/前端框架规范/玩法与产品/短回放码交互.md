# 短回放码客户端交互规范

回放码输入仅接受 6、7、8、11 位纯数字，并支持桌面键盘粘贴和移动端粘贴。客户端始终以 `lookupType=REPLAY_CODE` 请求 Hall；收到 `SHORT` 后直接打开返回的 `roomId + setId` 小局，收到 `LEGACY_11` 后才进入旧回放适配器，不按长度之外的特征猜测路由。

用户 ID 输入属于独立显式模式 `PLAYER_ID`：首位非零、至少 5 位，未来自然增长且无业务固定最大位数。它与回放码的长度重叠，界面和协议字段不得复用隐式判断。当前其他玩家战绩没有关系授权模型，因此只能查询本人，不得把用户 ID 错映射为某一局。

小结算显示当前小局短码；分享按钮先取得服务端稳定码并复制，再打开分享面板。加载、格式、不存在、过期、权限、冲突耗尽和回放未生成错误必须显示服务端语义；提交期间按钮逻辑单飞，关闭弹窗后的迟到响应不得打开回放。
