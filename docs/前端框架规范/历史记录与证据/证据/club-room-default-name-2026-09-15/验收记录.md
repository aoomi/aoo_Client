# 房费设置默认房间名验收

- 需求：新建模板房进入房费设置时，用玩法名称与底分自动填写房间名称；例如凉山跑得快、底分2，生成“跑得快2分”。
- 实现：创建房间入口传递权威`displayName`和`classificationName`；房费设置移除地区前缀后拼接`baseScore`与“分”。编辑已有模板时保留已有`roomName`，不覆盖用户名称。
- 诊断日志：`[ClubRoomFee] form-ready`记录clubId、gameCode、baseScore、最终roomName及是否恢复已有名称，不记录敏感信息。
- 静态验证：专项测试`club-room-fee-default-name.test.mjs` 1/1通过；本次两个TypeScript文件无新增类型错误。综合旧测试在本次断言前被`LegacyClubMainController.ts`既有入口断言阻塞，未修改该冻结范围。
- Creator同步：Creator 3.8.8自动热编译，Preview chunks包含`gameDisplayName`、`classificationName`和`[ClubRoomFee] form-ready`。
