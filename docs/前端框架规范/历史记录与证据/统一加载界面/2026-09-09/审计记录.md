# 唯一公共 WaitForm 加载链路审计

## 审计结论

- 唯一目标资源为 `assets/Common/Prefab/Common/WaitForm.prefab`，其目录属于 `common-prefab` Bundle；`LegacyFormManager` 对逻辑名 `UIWaitForm` 的规范化结果为 `WaitForm`，能够命中该资源。
- 大厅 `LegacyLobbyScreen` 已通过 `LegacyFormManager` 的加载计数，在普通表单加载超过 800ms 时显示 `UIWaitForm`，加载结束后关闭。
- 当前仍存在并行的 HTML `PresentationTransitionCoordinator`：普通 Prefab 预载/首次显示在 120ms 后会先显示 DOM 加载遮罩，之后才可能显示公共 WaitForm，不符合“除进入登录界面和进入游戏房间外只使用唯一 WaitForm”的最终目标。
- `game-return-lobby` 仍使用 DOM 加载遮罩；返回大厅不属于用户声明的两个例外，应迁为公共 WaitForm。
- 登录初始化、导航到登录界面以及进入游戏房间属于明确例外，可以继续使用首帧/场景过渡层；创建房间到进入游戏房间是同一次房间交接，也归入进入游戏房间例外。
- 亲友圈页面内部的 `loading/node_loading/loadingNode` 是列表内容状态，不是全屏加载界面；是否改为全屏 WaitForm 会改变亲友圈交互，且超出框架岗位边界，本轮不修改。

2. 将游戏返回大厅的正常加载展示迁为公共 WaitForm，并保证场景切换后由大厅最终挂载关闭。
