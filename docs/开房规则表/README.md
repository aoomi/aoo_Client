# Aoo 开房规则表索引

## 统一存放规则

1. 本目录只存放用户维护的开房规则配置表及本索引；全部配置表严格只读，任何AI或工具不得修改、重新保存、移动、重命名或改变元数据。
2. 正式玩法规则文档统一存放在[`前端框架规范/玩法与产品/玩法规则`](../前端框架规范/玩法与产品/玩法规则/README.md)，按`<玩法>/`分类维护公共规则、地区规则和目录索引。
3. 配置表是玩法可选项、配置语义和默认勾选状态的唯一权威来源；正式文档和代码必须服从配置表，发现冲突时不得反向修改配置表。
4. 规则含义存在歧义或冲突时，只记录待确认项并停止相关实现写入，等待用户确认。
