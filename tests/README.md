# 自动测试目录

此目录与 `assets` 同级，保存自动测试代码、测试数据和测试报告，不作为游戏运行资源打进正式 Bundle。

## 分类

- `unit`：规则、工具、数据模型等单元测试。
- `protocol`：登录、建房、进房、准备、出牌和结算协议测试。
- `ui`：按钮节点、弹窗、页面跳转和 Prefab 显示测试。
- `e2e`：登录到大厅、亲友圈、房间、牌局和结算的完整测试。
- `games`：各子游戏专属测试，当前先建立 NJPDK。
- `fixtures`：固定牌局、账号和测试配置数据。
- `reports`：自动生成的问题报告、截图、录像和日志。

`reports` 属于生成结果，不应提交为游戏运行资源。
